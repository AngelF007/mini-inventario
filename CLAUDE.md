# Mini Inventario — instrucciones para el agente

## Qué es
Mini Inventario es una web de inventario (alta, consulta y edición de productos).

## Entorno
- Node.js 22 (22.20 o superior) para la web.
- Python 3.12 para el servidor MCP.
- En Windows se trabaja en PowerShell 7 y se instala con Scoop.

## Reglas
1. Cada cambio va en una rama nueva y se integra con pull request. Nunca hagas commit directo en `main`.
2. Nunca subas llaves, tokens ni archivos `.env`. Usa `.env.example` sin valores reales.
3. Pide aprobación antes de borrar datos, archivos o ramas.
4. Pide aprobación antes de desplegar.
5. Antes de ejecutar un comando, explica qué hace.
6. Respuestas y documentación en español.
