# Mini Inventario

Web de inventario sencilla, construida paso a paso durante el curso.

## Requisitos

- Node.js 22 (22.20 o superior)
- Python 3.12

## Cómo empezar

```bash
git clone https://github.com/AngelF007/mini-inventario.git
cd mini-inventario
node --version     # debe mostrar v22.x
python --version   # debe mostrar 3.12.x
```
